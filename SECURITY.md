# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Email **trystan.frederick@gmail.com** with the subject line `[Security] Starfysh` and include:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- Any suggested mitigations you have identified

You will receive an acknowledgement within 48 hours. We aim to release a patch within 14 days for confirmed vulnerabilities, depending on severity and complexity.

We ask that you give us reasonable time to address the issue before any public disclosure.
